# CubeEvil4 v0.41.2 (Alpha)

> **⚠️ Early alpha for testers.** Expect bugs and keep a copy of your saves (app menu → Memory card →
> Export Savegames).

## Fixed

- Leon and Ashley now step onto and off the cable car in their right places; Ashley could end up
  far outside the world, which crashed the game in v0.41.0.

## Update

Install `CubeEvil4-v0.41.2-alpha.apk` over v0.41.1; discs, saves and settings stay. New here? See
the [README](https://github.com/Andiweli/CubeEvil4-Android#readme) for requirements and first
steps.

**Found a bug?** Keep "Record the error log" on (app menu → Error log, on by default) and send the
report right away: app menu (SELECT) → Error log → **Send report**, on
[Discord](https://discord.gg/AB3WVBqD5G) or as an issue here.
