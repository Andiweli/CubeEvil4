# CubeEvil4 v0.45.1 (Alpha)

> **⚠️ Early alpha for testers.** Expect bugs and keep a copy of your saves (app menu → Memory card →
> Export Savegames).

## Fixed

- Fewer hitches when an effect appears for the first time: shaders are now built on a background
  thread instead of in the middle of a picture.

## New

- Auto resolution adapts while you play: one level lower when the GPU can't keep up, back up when it
  can.
- The game and graphics threads stay on the fast CPU cores, and Android 13+ gets a hint to keep the
  clocks up.
- The app brings a list of known shaders and prepares them ahead, even on the first start.

## Changed

- Error reports now include the shaders your device built, so the next version can prepare them for
  everyone.

## Update

Install `CubeEvil4-v0.45.1-alpha.apk` over v0.45.0; discs, saves and settings stay. New here? See the
[README](https://github.com/Andiweli/CubeEvil4-Android#readme) for requirements and first steps.

**Found a bug?** Keep "Record the error log" on (app menu → Error log, on by default) and send the
report right away, without closing the game first: app menu (SELECT) → Error log → **Send report**,
on [Discord](https://discord.gg/AB3WVBqD5G) or as an issue here.
