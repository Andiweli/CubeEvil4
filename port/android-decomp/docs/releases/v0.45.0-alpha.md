# CubeEvil4 v0.45.0 (Alpha)

> **⚠️ Early alpha for testers.** Expect bugs and keep a copy of your saves (app menu → Memory card →
> Export Savegames).

## Fixed

- The ending works again: the jet ski no longer drives off into nowhere and the picture is back.
- Enemies should no longer stay silent when they die in big fights.
- Swiping out of the attache case no longer flashes the Exit tab, and the map no longer moves under
  your finger.

## New

- The graphics use more CPU cores: smoother on weaker phones.
- Touch in the inventory: tap key items, files and the map; swipe left or right to change the tab.
- New effects stutter less: the app prepares their shaders in quiet moments (from the second start
  on).

## Changed

- Less graphics data per picture goes to the GPU.
- The error log shows where the time of a picture goes and when enemies hold back.

## Update

Install `CubeEvil4-v0.45.0-alpha.apk` over v0.44.0; discs, saves and settings stay. The first start
prepares the shaders anew, so it can stutter a little once. New here? See the
[README](https://github.com/Andiweli/CubeEvil4-Android#readme) for requirements and first steps.

**Found a bug?** Keep "Record the error log" on (app menu → Error log, on by default) and send the
report right away, without closing the game first: app menu (SELECT) → Error log → **Send report**,
on [Discord](https://discord.gg/AB3WVBqD5G) or as an issue here.
