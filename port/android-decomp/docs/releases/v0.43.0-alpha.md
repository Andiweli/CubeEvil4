# CubeEvil4 v0.43.0 (Alpha)

> **⚠️ Early alpha for testers.** Expect bugs and keep a copy of your saves (app menu → Memory card →
> Export Savegames).

## Fixed

- No more crash at an elevator late on the island (and at other elevators that change the room).
- On 32-bit phones, no more crash in the castle hall with the fire-breathing dragon heads.
- On 32-bit phones, a hidden cause of crashes when a movie starts is gone.
- On 64-bit phones, the laser beams in the island corridor are drawn where they really hit, instead
  of cutting Leon with invisible beams.
- Items without a place in the attache case (weapons from the game's debug menu, saves changed by
  the hidden debug editor up to v0.41.3) get a free place, and the "E" mark no longer sits in the
  middle of the inventory.

## New

- Picture format "Stretched" in the app menu, next to 4:3 and 16:9.
- "Latch B" for the touch controls: one tap keeps Leon running until the next tap.
- A sensitivity slider for gyro aiming (0.5× to 3×).
- At start the app checks how your GPU draws the movie colours and writes the result to the error
  log (for the green movies some phones show).
- The error log now holds the app's own lines on every Android version, Android 10 and older too.

## Changed

- Picture format order: 4:3 (Original) first, then 16:9 and Stretched.
- A little more space between the lines of the app menu; the gyro option is called "Gyro aiming".

## Update

Install `CubeEvil4-v0.43.0-alpha.apk` over v0.42.1; discs, saves and settings stay. New here? See
the [README](https://github.com/Andiweli/CubeEvil4-Android#readme) for requirements and first
steps.

**Green or odd movie colours?** Watch the opening movie for a few seconds, then send a report: app
menu (SELECT) → Error log → **Send report**, on [Discord](https://discord.gg/AB3WVBqD5G) or as an
issue here.

**Found a bug?** Keep "Record the error log" on (app menu → Error log, on by default) and send the
report right away, without closing the game first: app menu (SELECT) → Error log → **Send report**,
on [Discord](https://discord.gg/AB3WVBqD5G) or as an issue here.
