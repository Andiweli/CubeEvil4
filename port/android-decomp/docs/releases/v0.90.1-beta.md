# CubeEvil4 v0.90.1 (Beta)

> **Beta.** The whole game can be played from start to finish. Expect bugs and keep a copy of your
> saves (app menu → Memory card → Export Savegames).

## Fixed

- With "Use performance cores", the game and graphics threads stay on the fast cores; some phones moved them to the slow ones after a while.

## New

- Force Performance in the app menu (Graphics): "Use performance cores" keeps the game on the fast CPU cores; smoother on many phones, but warmer. "Default" lets Android decide.
- The touch controls' editor can add an R3 button (graphics capture for error reports).

## Changed

- The app now knows 8068 shaders instead of 4266, so the castle and much of the island stutter less the first time.
- The error log names a disc file that is shorter on the device than on the disc (import the disc again).

## Update

Install `CubeEvil4-v0.90.1-beta.apk` over v0.90.0; discs, saves and settings stay. On the first start
the app prepares the new shaders in the background for a few minutes; you can play meanwhile.

**Found a bug?** Keep "Record the error log" on (app menu → Error log, on by default) and send the
report right away, without closing the game first: app menu (SELECT) → Error log → **Send report**,
on [Discord](https://discord.gg/AB3WVBqD5G) or as an issue here. Reports also bring the shaders of
your device into the next update.
