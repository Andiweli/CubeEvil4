# CubeEvil4 v0.38.0 – Alpha 1

> **⚠️ Work in progress.** This is an early alpha for testers. Expect crashes, graphics errors and
> other bugs, and keep a copy of your saves (app menu → Memory card → Export). The game is the
> debug build of 2004; use its debug menu with care.

CubeEvil4 is an unofficial, native Android port of the GameCube debug build of Resident Evil 4.
It runs the original game code on your device; it is not an emulator and not a remake.

## What you need

- Android 6.0 or later, OpenGL ES 3.0, ARM 32- or 64-bit (one APK for both)
- A game controller (built in, USB or Bluetooth); no touch controls
- Your own disc images (ISO or GCM) of **both** discs of the GameCube debug build from
  November 25, 2004 (`G4BE08`). No game data is included.

## Install

1. Download `CubeEvil4-v0.38.0-alpha1.apk` below and install it (allow installing from this
   source when Android asks).
2. Open **CubeEvil4**, choose **Import Disc 1** and **Import Disc 2**, then **Start game**.

**Coming from an earlier test build ("Resident Evil 4 Android")?** CubeEvil4 installs as a new
app next to it. Export your saves in the old app first (SELECT → Memory card → Export), import
them in CubeEvil4 (SELECT → Memory card → Import), import both discs again, then uninstall the old
app.

## What works

- Title screen, menus and the opening movie with sound
- The police car ride and the start of the village (stage 1-1): walking, aiming, shooting,
  enemies, map and inventory
- Saving at the typewriter and loading from the title screen; memory card import and export as
  `.gci` (Dolphin and GameCube)
- Sound and music through the game's own sound code; the movies of both discs
- Controller like the GameCube pad, with vibration
- App menu (SELECT): resolution (1080p and above), anti-aliasing, texture filter, 16:9 or 4:3,
  FPS display, depth of field, error report
- 32- and 64-bit devices; on the PC both run the tested parts frame by frame identically

## Still in testing

- Everything after the start of the village: later rooms and chapters have not been played
  through yet and may crash or show graphics errors
- Saving and loading on 64-bit devices (passed on the PC, not yet confirmed on a device)
- Devices and graphics chips other than the two tested so far (Retroid Pocket Flip 2 with
  Android 13, POCO X7 Pro with Android 16), and speed on weaker devices

## Not yet

- Touch controls
- The retail version of the game (only the debug build of November 25, 2004 is supported)
