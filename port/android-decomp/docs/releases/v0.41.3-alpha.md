# CubeEvil4 v0.41.3 (Alpha)

> **⚠️ Early alpha for testers.** Expect bugs and keep a copy of your saves (app menu → Memory card →
> Export Savegames).

## Fixed

- Novistadors (the insects) could end up at an invalid position; in the room with the crushing
  pistons Leon then died at once, also after every Continue.
- The targets of the shooting gallery no longer keep coming back, and the gallery no longer crashes.

## New

- The error log records enemies (appear, hits with body part and weapon, lost heads), the cursor
  in menus with both sticks, every room start and every death with its cause.

## Update

Install `CubeEvil4-v0.41.3-alpha.apk` over v0.41.2; discs, saves and settings stay. New here? See
the [README](https://github.com/Andiweli/CubeEvil4-Android#readme) for requirements and first
steps.

**Found a bug?** Keep "Record the error log" on (app menu → Error log, on by default) and send the
report right away, without closing the game first: app menu (SELECT) → Error log → **Send report**,
on [Discord](https://discord.gg/AB3WVBqD5G) or as an issue here.
