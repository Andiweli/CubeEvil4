# CubeEvil4 v0.42.1 (Alpha)

> **⚠️ Early alpha for testers.** Expect bugs and keep a copy of your saves (app menu → Memory card →
> Export Savegames).

## Fixed

- No more crash when Ashley is hit or grabbed on the bulldozer on the island.
- No more occasional crash while a room loads or after continuing from a checkpoint.
- Some objects in three castle rooms and one island room are no longer drawn with random
  transparency.
- On 64-bit phones, effects no longer switch on in the wrong place in the village and four other
  rooms.

## New

- The error log records how much processor time the game and the drawing take per picture and on
  which processor cores they run, to find what slows the game down on weaker phones.

## Update

Install `CubeEvil4-v0.42.1-alpha.apk` over v0.42.0; discs, saves and settings stay. New here? See
the [README](https://github.com/Andiweli/CubeEvil4-Android#readme) for requirements and first
steps.

**Slow on your phone?** Play a few minutes in the village, then send a report: app menu (SELECT) →
Error log → **Send report**, on [Discord](https://discord.gg/AB3WVBqD5G) or as an issue here.

**Found a bug?** Keep "Record the error log" on (app menu → Error log, on by default) and send the
report right away, without closing the game first: app menu (SELECT) → Error log → **Send report**,
on [Discord](https://discord.gg/AB3WVBqD5G) or as an issue here.
