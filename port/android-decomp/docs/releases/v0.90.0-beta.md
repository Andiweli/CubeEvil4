# CubeEvil4 v0.90.0 (Beta)

> **First beta.** The whole game can be played from start to finish (a tester finished it on a
> phone). Expect bugs and keep a copy of your saves (app menu → Memory card → Export Savegames).

## Fixed

- Ganados shot off roofs, cable cars or walls with the shotgun scream while they fall again.
- Ashley no longer calls for help next to the shooting gallery's targets.
- Lights no longer swim when the camera turns in 60 FPS mode.
- Rumble is felt in play again: shots and hits now give a short, clear buzz.

## New

- The game has been played through on a phone, from the village to the end credits.
- Quick-time events by touch: tap the button prompt that flashes up (tap repeatedly to mash).

## Changed

- The app now knows 4266 shaders instead of 627, so the village, the lake, much of the castle and
  the island's finale stutter less the first time.

## Update

Install `CubeEvil4-v0.90.0-beta.apk` over v0.46.0; discs, saves and settings stay. On the first start
the app prepares the shaders in the background for about a minute, longer on slower phones; you can
play meanwhile. New here? See the [README](https://github.com/Andiweli/CubeEvil4-Android#readme) for
requirements and first steps.

**Help with the rest of the castle and the island:** many of their shaders are still missing. Play
there and send a report: app menu (SELECT) → Error log → **Send report**, on [Discord](https://discord.gg/AB3WVBqD5G)
or as an issue here. Your shaders go into the next update.

**Found a bug?** Keep "Record the error log" on (app menu → Error log, on by default) and send the
report right away, without closing the game first.
