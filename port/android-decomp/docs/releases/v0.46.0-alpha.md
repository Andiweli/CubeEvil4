# CubeEvil4 v0.46.0 (Alpha)

> **⚠️ Early alpha for testers.** Expect bugs and keep a copy of your saves (app menu → Memory card →
> Export Savegames).

## Fixed

- Long labels in the app menu that wrap onto a second line are no longer cut off.
- The dynamic resolution no longer drops a level just because a room loads or a short hitch happens.

## New

- The FPS display shows the resolution in use after the Hz, e.g. "1280×672 (2×)".
- "Latch L and R" and "Latch B" now work with a controller too.
- Gyro aiming works with the harpoon in the boat at the lake.

## Changed

- The resolution option "Auto" is now called "Dynamic".
- The latch switches moved to Comfort Controls.
- The app's list of known shaders grew from 70 to 627, so fewer effects stutter the first time.

## Update

Install `CubeEvil4-v0.46.0-alpha.apk` over v0.45.0 or v0.45.1; discs, saves and settings stay. New here? See the
[README](https://github.com/Andiweli/CubeEvil4-Android#readme) for requirements and first steps.

**Found a bug?** Keep "Record the error log" on (app menu → Error log, on by default) and send the
report right away, without closing the game first: app menu (SELECT) → Error log → **Send report**,
on [Discord](https://discord.gg/AB3WVBqD5G) or as an issue here.
