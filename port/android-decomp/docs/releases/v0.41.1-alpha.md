# CubeEvil4 v0.41.1 (Alpha)

> **⚠️ Early alpha for testers.** Expect bugs and keep a copy of your saves (app menu → Memory card →
> Export Savegames).

## Fixed

- No more crash when Ganados look for their way to Luis in the cabin (chapter 2-3, 64-bit devices).
- The error log now records on every phone: the game core writes its own log file (some phones,
  e.g. Samsung, recorded nothing).

## New

- The app menu in Arabic, Chinese (simplified), French, Hindi, Italian, Portuguese, Russian and
  Spanish (it follows your phone's language; Android 13+: also per app under Settings → Apps →
  CubeEvil4 → Language).

## Changed

- The error report says whether the error log was on.

## Update

Install `CubeEvil4-v0.41.1-alpha.apk` over v0.41.0; discs, saves and settings stay. New here? See
the [README](https://github.com/Andiweli/CubeEvil4-Android#readme) for requirements and first
steps.

**Found a bug?** Keep "Record the error log" on (app menu → Error log, on by default) and send the
report: app menu (SELECT) → Error log → **Send report**, on
[Discord](https://discord.gg/AB3WVBqD5G) or as an issue here.
