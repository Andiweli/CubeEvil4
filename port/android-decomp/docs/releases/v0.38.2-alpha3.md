# CubeEvil4 v0.38.2 – Alpha 3

> **⚠️ Work in progress.** This is an early alpha for testers. Expect crashes, graphics errors and
> other bugs, and keep a copy of your saves (app menu → Memory card → Export Savegames). The game
> is the debug build of 2004; use its debug menu with care.

An update of Alpha 2: touch controls, gyro aiming, a second button layout, a faster start and
fixes from your reports. Thank you for testing!

## New

- **Touch controls.** They appear on their own when no controller is connected. In the app menu
  (SELECT), **Use Touch Controls** shows them always. The menu icon on screen opens the layout
  editor to arrange the buttons; MENU there is SELECT, and L and R stay pressed until you
  tap them again. The buttons use the colours of the GameCube controller.
- **Gyro aiming** (app menu → **Use Gyro-Aiming**, on devices with a gyroscope): while you aim a
  gun, turning the device moves the aim. It does nothing before you aim.
- **Alternate Controls** (app menu → **Alternate Controls**), a second button layout:

  | Button | Function |
  | --- | --- |
  | L1 | Ready the knife |
  | L2 | Aim |
  | R1 | Inventory (Weapons/Recovery) |
  | R2 | Fire, or slash with the knife ready |
  | Y | Map |
  | X | Ashley (wait / follow), as before |
  | A, B, START | as before |

## Improved

- **Faster start:** the black screen before the first logo is about 2 seconds instead of about
  6 (Retroid Pocket Flip 2).
- **Resolution "Auto"** now picks one step lower (2× on 1080p screens) for a steadier speed.
- **Depth of field:** its autofocus now moves smoothly from one distance to the next instead of
  jumping.
- **Screens with 90 or 120 Hz:** the app asks for 60 Hz, or shows each picture for an even number
  of refreshes, for an even pace. Please tell us how it runs on your device.
- **App menu** tidied up: "Back to the game" at the top, memory card export and import as
  `.gci` with two buttons, error log options in one row, and a link to this project.

## Fixed

- **Thin things such as tree branches flickered for a moment** with anti-aliasing (MSAA) and
  depth of field on: for a single picture the autofocus measured a wrong distance and blurred
  them.
- **The light puzzle in the church** could not be solved on 64-bit devices (the game waited
  forever).
- **Game core does not start on a 32-bit device** ("MEM1 … is taken in this process"): the app
  now reserves this memory earlier, and the error report names what holds it. If you see this
  message, please press **Send report** in the error dialog and send us the file.

## Update from v0.38.1

Install `CubeEvil4-v0.38.2-alpha3.apk` over v0.38.1. Your imported discs and your saves stay.

## Known issues

- **Short stutters the first time a scene appears.** The graphics programs (shaders) for each new
  scene are prepared once on your device and then kept; after that the same scene runs smoothly.
- **Anti-aliasing (MSAA)** costs a lot of speed on many devices: 4× MSAA at a high resolution
  can drop below 30 pictures a second. Use 2× or Off if the game feels slow.
- Everything listed under "Still in testing" below.

## What you need

- Android 6.0 or later, OpenGL ES 3.0, ARM 32- or 64-bit (one APK for both)
- A game controller (built in, USB or Bluetooth) or the touch screen
- Your own disc images (ISO or GCM) of **both** discs of the GameCube debug build from
  November 25, 2004 (`G4BE08`). No game data is included.

## First install

1. Download `CubeEvil4-v0.38.2-alpha3.apk` below and install it (allow installing from this
   source when Android asks).
2. Open **CubeEvil4**, choose **Import Disc 1** and **Import Disc 2**, then **Start game**.

## What works

- Title screen, menus and the opening movie with sound
- The police car ride and the village of chapter 1: walking, aiming, shooting, enemies, map and
  inventory
- Saving at the typewriter and loading from the title screen, on 32- and 64-bit devices; memory
  card import and export as `.gci` (Dolphin and GameCube)
- Sound and music through the game's own sound code; the movies of both discs
- Controller like the GameCube pad, with vibration, or the alternate layout; touch controls;
  gyro aiming
- App menu (SELECT): resolution, anti-aliasing, texture filter, 16:9 or 4:3, FPS display, depth
  of field, controls, memory card, error report

## Still in testing

- Later chapters have not been played through yet and may crash or show graphics errors
- Devices and graphics chips other than the two tested so far (Retroid Pocket Flip 2 with
  Android 13, POCO X7 Pro with Android 16), and speed on weaker devices

## Not yet

- The retail version of the game (only the debug build of November 25, 2004 is supported)
